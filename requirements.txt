# pip dependency (github.com/Erlbon/redactor_common), not a vendored
# copy: previously each of the three projects hand-copied this file
# tree in separately, so a fix to shared code needed three separate
# manual resyncs and could silently drift out of sync (which is exactly
# what happened -- see that repo's CHANGELOG-equivalent commit history
# around the setWindowModality crash fix). Pinned to a tag, not @main --
# see that repo's README ("Releasing a new version") for how to bump
# this pin deliberately when it changes, rather than floating and
# having one bad push there break this project's next install.

# aubio-ledfx, not plain "aubio" -- the original aubio PyPI package is
# source-only (no Windows wheels, ever), so pip always tries to compile
# a C extension and needs MSVC Build Tools. aubio-ledfx is a maintained
# fork (by the LedFx project, which hit the same problem) that ships
# real prebuilt Windows wheels, including for newer Python versions the
# original has never built for. Same source tree, same `import aubio`
# in code -- only the pip package name differs. Third-party fork, not
# the canonical aubio release; swap back to plain "aubio" (+ MSVC Build
# Tools) if that provenance ever becomes a concern.
aubio-ledfx
